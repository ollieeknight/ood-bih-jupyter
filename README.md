# Open OnDemand Jupyter

An interactive Open OnDemand app that launches JupyterLab or Jupyter Notebook, with Python provided via conda or [pixi](https://pixi.sh).

Forked from [bihealth/ood-bih-jupyter](https://github.com/bihealth/ood-bih-jupyter), itself based on [OSC/bc_osc_jupyter](https://github.com/OSC/bc_osc_jupyter).

For colleague-facing setup instructions, see the [bih-cubi-romagnani](https://github.com/Romagnani-Lab/bih-cubi-romagnani) repository.
